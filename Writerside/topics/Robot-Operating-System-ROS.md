# Robot Operating System (ROS2, Humble)

The AIDDL ROS2 Bridge [1] establishes a connection between `aiddl-external-grpc`
and ROS2. It relies on `aiddl-external-ros2` [2] for message conversions.


[1] https://github.com/uwe-koeckemann/aiddl-ros2-bridge/
[2] https://github.com/uwe-koeckemann/AIDDL/tree/master/external/ros2
